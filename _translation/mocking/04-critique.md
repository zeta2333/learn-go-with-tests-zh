# 04 — 批判性审校：初译稿 vs 原文（只诊断）

## Accuracy

- **"整个测试就要多跑 3 秒"**：原文 "Are we happy with 3s added to the test run for every new test of `Countdown`?"——"test run" 指*一轮测试运行*，"整个测试"表述含混；且前半句"`Countdown` 每多一个测试"主语粘连。→ 改"`Countdown` 每多一个新测试，测试运行就要多上 3 秒，我们乐意吗？"
- **"把这件事表达成接口的事实标准就是 `io.Writer`"**："capturing that as an interface" 的"抽象/捕获"义弱化成"表达"，句子还有"事实标准到底修饰谁"的歧义。→ 改"而想把这件事抽象成接口，Go 里事实上的标准就是 `io.Writer`"。
- **"把依赖注入成我们的 Spy"**："inject a dependency on our Spy" 译反了语感（注入的是 Spy 这个依赖）。→ 改"把我们的 Spy 当作依赖注入进去"。
- **"这个测试里没有任何新东西"**："There should be nothing new in this test" 的推测语气（should be）丢了对读者预期管理。→ 改"这个测试应该不会有什么新东西"。

## Native Voice

- **"_抽象糟糕_"**：搭配生硬（"抽象"不作"糟糕"的先行词这样倒装）。→ 改"_糟糕的抽象_"，整句"mock 用得太多，通常指向的是代码里的_糟糕抽象_"。
- **"_不尊重重构阶段_"**：直译腔（"尊重阶段"中文不这么搭）。→ 改"_没把重构阶段当回事_"，与前半"_不_听测试的话_"口语度对齐。
- **"更透彻地理解 mock 的门道"**："门道"略显油滑，与全书平实语气稍隔。→ 改"更透彻地理解该怎么 mock"。
- **"这通常意味着"** 后接列表无冒号，中文标点习惯补"："。
- **"数到零时打印 "Go!" 然后退出"**：原文 "when it reaches zero"（实际先打 3/2/1），原文本身即如此措辞，保留不改。
