# 构建一个应用

现在你大概已经消化了*Go 基础*篇，对 Go 的大部分语言特性和如何做 TDD 有了扎实的根基。

接下来的一节将涉及构建一个应用。

每一章都会在前一章的基础上迭代，按照我们的产品负责人（product owner）的指示扩展应用的功能。

我们会引入一些新概念来帮助写出优秀的代码，但大部分新内容将是学习用 Go 的标准库能做成什么。

到最后，你应该对如何以测试为后盾、迭代式地用 Go 编写一个应用有很强的把握。

- [HTTP 服务器](https://github.com/quii/learn-go-with-tests/blob/main/http-server.md)（英文原版） - 我们将创建一个监听 HTTP 请求并响应它们的应用。
- [JSON、路由与嵌入](https://github.com/quii/learn-go-with-tests/blob/main/json.md)（英文原版） - 我们会让端点返回 JSON，并探索如何进行路由。
- [IO 与排序](https://github.com/quii/learn-go-with-tests/blob/main/io.md)（英文原版） - 我们会把数据持久化到磁盘并从中读取，还会讲到数据排序。
- [命令行与项目结构](https://github.com/quii/learn-go-with-tests/blob/main/command-line.md)（英文原版） - 从一份代码库支持多个应用，并从命令行读取输入。
- [Time](https://github.com/quii/learn-go-with-tests/blob/main/time.md)（英文原版） - 使用 `time` 包来安排活动。
- [WebSockets](https://github.com/quii/learn-go-with-tests/blob/main/websockets.md)（英文原版） - 学习如何编写和测试一个使用 WebSockets 的服务器。
