# 01 — Math 章分析

## 内容概述

全书最长的一章（约 9.3k 词），用"画 SVG 模拟时钟"贯穿完整 TDD 循环：

1. **问题与验收测试**：目标是从 `time.Time` 生成带时针/分针/秒针的时钟 SVG。先解析 SVG（XML 圆 + 三条线），确定关键参数（圆心 150,150；针长 90/80/50；SVG 原点在左上角）。引入验收测试（acceptance test）概念，配 Nat Pryce/Steve Freeman 的 outside-in 经典图。
2. **数学准备**：单位圆 + 三角函数——X=cos(a)、Y=sin(a)；因从 12 点方向量角，改为 x=sin(a)、y=cos(a)；`math.Cos` 收弧度（2π=一整圈）。
3. **秒针 TDD 全流程**：`secondsInRadians`（π/30 每秒）→ 首撞浮点不精确（π≠π*30/30），对策是"重排等式只做除法"；顺带讲除零（编译错误 vs 运行时 +Inf）；`secondHandPoint` 再撞浮点（1.22e-16），引出 `roughlyEqualFloat64`（阈值 1e-7）近似相等；`SecondHand` 做 scale（×90）→flip（-Y，适应左上原点）→translate（+150）。
4. **画时钟与 SVG 重构**：先写了个 `main.go` 拼字符串版，自嘲很丑；自省出两大坏味道（`SecondHand` 与 SVG 深度耦合却没产出 SVG 测试；用字符串包含断言 XML "又脆弱又不敏感"），转向 `encoding/xml` + `xml.Unmarshal`，用 zek/xml-to-go 生成 `Svg` 结构体，逐步精化为 `SVG/Circle/Line` 类型（`float64` 属性）+ `containsLine` 辅助函数；`%f` 六位小数陷阱 → `%.3f`。
5. **分针、时针**：`minutesInRadians` = `secondsInRadians(t)/60 + π/(30/min)`（每秒挪一丁点）；引 Kent Beck 名言"把测试写到恐惧变成无聊为止"；`angleToPoint` DRY 掉 sin/cos 重复；`hoursInRadians` 需 `%12`（非 24 小时制）+ 复用分针角度 ÷12，再次靠 `roughlyEqualFloat64` 过关。
6. **TDD 狂热之辩**：一次写两个用例是不是"坏 TDD"？——TDD 是工具不是宗教，信心涨了步子就可以迈大，但测试仍先写。
7. **总结**：程序 + 库（引 Henry Spencer《The Art of Unix Programming》名言）；"最有价值的测试"——最懂 SVG 的代码在测试里，`what` 在测试、`how` 在代码，测试不是二等公民，是投资。

## 翻译难点

- **TDD 循环标题高频重复**：`Write the test first`（9 次）、`Try to run the test`（13 次）、`Write the minimal amount of code...`（7 次）、`Write enough code to make it pass`（12 次）、`Refactor`（8 次）、`Repeat for new requirements`（10 次）——按 select/sync 章先例统一译法并保留重复，不得合并。
- **代码块多达 118 个**：go 块仅译 `//` 注释（Point/SecondHand/SVGWriter 的 godoc 注释、scale/flip/translate、REPLACE THIS!、fails to compile）；xml/纯文本块（错误输出、π 等式、目录树）逐字节保留；无 `// Output:`。
- **三个 blockquote 引文**：`math.Cos` godoc、Kent Beck 名言、Henry Spencer 书引——按先例译成中文，标识符与署名保留。
- **自嘲/英式幽默密集**：`How hard can that be?`、`Wait, you don't know what an acceptance test is yet`、`Behold, a passing test`、`Wait, what?`、`Floats are horrible`、`Hooray maths!`、`Oh boy am I not trying to win any prizes`、`This stinks... stink stink`、`Oooops!`、`the proof of the pudding`、`and not land on the moon`、`Floating point arithmetic strikes again`（又双叒）、`really, really WEIRD clocks`、`If - _when_ - we come back`——语气必须保住。
- **Jennifer Aniston 梗**：`Here comes the science bit`（英国 L'Oréal 广告梗），YouTube 链接原样保留，译文点出"科学环节到了"即可。
- **图片 9 张**：`example_clock.svg`、`TDD-outside-in.jpg`、`unit_circle.png`、`unit_circle_coords.png`、`unit_circle_params (1).png`、`unit_circle_12_oclock.png`、`clock.svg`、`clock (1).svg`、`clock (2).svg`；带空格文件名改 `-`，`<...>` 包裹在改写后可去掉；alt 文本意译。
- **末尾孤儿脚注**：源文件最后一行是编号列表项 "1. In short it makes it easier to do calculus..."，对应正文 "There are good reasons... we won't go in to"，上游脚注错位到了文末。按"段落顺序严格对应"原位保留翻译。
- **长解释段**：`projectpath` 占位符与外部测试包（`package clockface_test`）说明、字符串断言 XML 为何"太脆弱又不敏感"、SVG 的 what/how 之辨——都是多重复句，需拆短句保逻辑链。

## 原文疑似笔误（保留原样，报告用）

1. 文末孤儿编号项 "1. ..."（脚注错位）。
2. 工具名先写 `zek`，后文写 "generated by `zak`"。
3. "until we've got the some coverage"（the some）。
4. "a _new_ file called `clockface_test`"（应为 `clockface_test.go`）。
5. 示例 SVG DOCTYPE 声明 1.1 但 `version="2.0"`。
6. 测试输出模块路径不一致（`learn-go-with-tests/math/clockface` vs `clockface`）。
7. "Much in the same way as we produced the tests"（断句语病）；"highschool"（应为 high school）。
